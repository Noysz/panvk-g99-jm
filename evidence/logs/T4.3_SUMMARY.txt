HOW CORRECTNESS WAS DECIDED - no expected pixel count was hand-written.
  square: arithmetic. NDC +/-0.5 maps to pixel 16.0 and 48.0 in a 64x64
          viewport, so covered pixel centres are 16.5..47.5 = 32x32 = 1024.
  circle: no closed form, so a CPU rasterizer walks the same 64 triangles
          the shader builds and applies Vulkan's own coverage rule (pixel
          covered iff its centre is inside). GPU is compared per pixel.

  Pixel centres lying on an edge are UNDECIDABLE from one triangle at a
  time, so they are counted and reported, never scored. Measured, not
  assumed away: the smallest margin among scored pixels was 0.500000 px
  for the square and 0.002667 px for the circle, both far above float
  noise, so the scored comparison is unambiguous.
