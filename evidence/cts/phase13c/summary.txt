0075 null-combined-image-texture-slot
  Symptom      robustness2 bind.notemplate.*.sampled_image.no_fmt_qual.
               null_descriptor.* failed in the full l_rb2 run (25 cases) and
               passed when run alone.
  Trigger      any graphics case with a float format (r32f storage_buffer
               vert, r32f uniform_texel_buffer frag/vert) earlier in the same
               process; r32f compute and r32i graphics cases did not trigger
               it. After the trigger the r32i null cases failed in vert, frag
               and comp (pair runs, nulltex/pair_*.txt,
               nulltex/polluter_plus_46_null.txt). storage image, buffer and
               texel buffer null cases were not affected.
  Ruled out    shader binary: identical alone and after the trigger
               (BIFROST_MESA_DEBUG=shaders diff). Knobs without effect:
               PANVK_KBASE_SYNC_SUBMIT, PANVK_KBASE_DEVMEM_EAGER,
               PANVK_V9_NO_MINMAX, PANVK_MVJ_NO_ZERO, PANVK_V9_TEXEL_OOB_HW,
               PANVK_NULLDESC_POISON, PANVK_POOL_CACHE_MAX_MB=1. A temporary
               hook filling command pool BOs with 0x00 or 0xa5 changed
               nothing (stale pool memory ruled out). A temporary shader
               pass selecting 0 when the texture descriptor type is Null
               changed nothing; forcing 0 for all 1D texture results made
               the case pass, so the values came from texture reads and the
               slot did not hold a null descriptor. Both temporary changes
               were reverted (sources compared with stack17).
  Root cause   write_image_view_desc() wrote the null descriptor of a
               COMBINED_IMAGE_SAMPLER into the sampler sub-descriptor
               (get_sampler_subdesc_info), so the texture slot kept what the
               descriptor memory held. Same code in upstream Mesa (6598829).
  Fix          get_tex_subdesc_info(); control PANVK_NULL_TEX_SAMPLER_SLOT=1.
  Results      pair (r32f uniform_texel_buffer frag, r32i null 1d vert):
               3x Pass/Pass, control Pass/Fail. pair with 2d frag: Pass/Pass.
               polluter + 46 r32i null cases: only the known
               vertex_attribute_fetch null case fails.
               l_rb2 n15: 951 P / 28 F / 1670 NS (t13: 926 / 53 / 1670),
               25 Fail -> Pass, 0 lost (nulltex/n15_l_rb2.tsv).
               Regression rN15 vs rS14: 30 groups, 7127 cases, lost 0
               (regression_rN15_vs_rS14.txt).
